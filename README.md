# Prado Remotion Studio

20-second Toyota Prado VX Limited advertisement, price **210 000 сомонӣ**.

Run in Codespaces: `npm install` then `npm start`.

Upload original images to `public/` as `front.jpg`, `angle.jpg`, `interior.jpg`, `rear.jpg`.

Render: `npm run render`.

Photos, audio and MP4 are not yet included. The animation code uses Remotion only.
